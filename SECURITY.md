# Security

Report a suspected vulnerability privately through the repository's security advisory channel, when enabled, or to your installation operator. Do not disclose usable credentials, account recovery links, signed media URLs or personal data in public issues.

Include the affected version, expected behavior, a minimal reproduction and the impact. Use disposable accounts and objects. Do not publish a real post or test against someone else's installation without authorization.

See [the security guide](docs/security.md) for HTTPS, actor permissions, encryption, private media and publishing boundaries. Release publication is gated by source verification and image checks. Provider API access and approval are separate operator requirements.
