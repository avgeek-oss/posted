---

Read access: a read-enabled personal or team REST API key, or a signed-in user. OAuth clients use the corresponding MCP tool through /mcp.

Read a draft's text, selected accounts, overrides and ordered media.

Resolved media and mediaOverrides contain media objects. Saving uses mediaIds and mediaOverrides containing IDs.

MCP clients can use [`get_draft`](/mcp-reference/get_draft) for this operation.
