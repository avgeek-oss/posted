Read access: a read-enabled personal or team REST API key, or a signed-in user. OAuth clients use the corresponding MCP tool through /mcp.

List team drafts. Drafts never enter the delivery queue.

Drafts are team-owned and never enter the delivery queue. Pagination is numbered and pageSize is at most 100.

MCP clients can use [`list_drafts`](/mcp-reference/list_drafts) for this operation.
