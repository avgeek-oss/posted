Administrator access with explicit administrator permission on API keys or MCP credentials, or a signed-in administrator.

Update the team name.

Requires Administrator access. This changes the team name, not membership or provider ownership.

MCP clients can use [`update_team`](/mcp-reference/update_team) for this operation.
