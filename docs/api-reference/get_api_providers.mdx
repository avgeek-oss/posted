Read access: a read-enabled personal or team REST API key, or a signed-in user. OAuth clients use the corresponding MCP tool through /mcp.

Read enabled providers and their content limits.

Only fully configured providers appear. This returns Posted's enforced capabilities, not an assurance that a provider application has production approval.

MCP clients can use [`list_providers`](/mcp-reference/list_providers) for this operation.
