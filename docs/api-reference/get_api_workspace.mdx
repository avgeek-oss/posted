Read access: a read-enabled personal or team REST API key, or a signed-in user. OAuth clients use the corresponding MCP tool through /mcp.

Read team settings.

Posted has one team per installation. The wire response calls this object workspace.

MCP clients can use [`get_team`](/mcp-reference/get_team) for this operation.
