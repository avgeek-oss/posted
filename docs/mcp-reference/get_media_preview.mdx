Get a short-lived private URL to view approved media.

## Workflow

```mermaid
flowchart LR
  step0["Choose ready team media"] --> step1
  step1["Request a short-lived URL"] --> step2
  step2["Render privately before expiry"]
```

## Access and behavior

A Read-only, Write or Administrator OAuth grant can call this tool within the user’s current team role. Tools are listed and callable only when the current grant and role permit them.

Only approved, ready media from this team can be previewed. The URL is temporary and is not a permanent public attachment URL. Animated GIFs also return thumbnailUrl for a private still preview; open url to view the animation.

## Arguments

| Argument  | Required | Type or meaning                                       |
| --------- | -------- | ----------------------------------------------------- |
| `mediaId` | Yes      | Uploaded media UUID returned by reserve_media_upload. |

<Accordion title="Complete input schema">

```json
{
  "type": "object",
  "properties": {
    "mediaId": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    }
  },
  "required": ["mediaId"],
  "additionalProperties": false
}
```

</Accordion>

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_media_preview",
    "arguments": {
      "mediaId": "44444444-4444-4444-8444-444444444444"
    }
  }
}
```

## Example result

Posted returns this object in `structuredContent` and a JSON text content block. A tool failure sets `isError`; never treat an error as a completed mutation.

```json
{
  "url": "https://storage.example.test/signed-preview"
}
```
