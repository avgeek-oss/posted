Cancel pending deliveries. Ask the user before cancelling their post. Published posts remain in history.

## Workflow

```mermaid
flowchart LR
  step0["Read current delivery states"] --> step1
  step1["Confirm cancellation"] --> step2
  step2["Inspect which deliveries were cancelled"]
```

## Access and behavior

Write or Administrator OAuth consent and a member/administrator team role are required. Tools are listed and callable only when the current grant and role permit them.

Cancellation stops pending deliveries. It does not remove provider-side publications, and a group with work already preparing or publishing cannot be cancelled safely.

<Warning>
  Confirm the exact target and consequence with the user before calling this
  tool.
</Warning>

## Arguments

| Argument | Required | Type or meaning                                           |
| -------- | -------- | --------------------------------------------------------- |
| `postId` | Yes      | Posting-group UUID returned by list_posts or create_post. |

<Accordion title="Complete input schema">

```json
{
  "type": "object",
  "properties": {
    "postId": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    }
  },
  "required": ["postId"],
  "additionalProperties": false
}
```

</Accordion>

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "cancel_post",
    "arguments": {
      "postId": "22222222-2222-4222-8222-222222222222"
    }
  }
}
```
