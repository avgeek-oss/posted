Save incomplete content without publishing. Use version 0 and a new draftId for a new draft, or its current version to update. Reuse the request key for retries.

## Workflow

```mermaid
flowchart LR
  step0["Choose a new draft ID or read a draft"] --> step1
  step1["Save with version and request key"] --> step2
  step2["Keep the returned version"]
```

## Access and behavior

Write or Administrator OAuth consent and a member/administrator team role are required. Tools are listed and callable only when the current grant and role permit them.

Use version 0 for a new UUID, or the latest version for an update. Reuse the same idempotencyKey and identical content when retrying. Incomplete content is allowed. Saving does not publish.

## Arguments

| Argument          | Required | Type or meaning                                                                             |
| ----------------- | -------- | ------------------------------------------------------------------------------------------- |
| `text`            | Yes      | Master text for this post. Account overrides take precedence.                               |
| `textOverrides`   | No       | Selected connection ID to custom text; omit a key to inherit the master.                    |
| `additionalPosts` | No       | Later posts in order; each has text, mediaIds and optional account overrides.               |
| `connectionIds`   | Yes      | Selected connected accounts belonging to this team; applies to the complete sequence.       |
| `mediaIds`        | Yes      | Ready media IDs in attachment order for this master post.                                   |
| `mediaOverrides`  | No       | Selected connection ID to ordered media IDs; omit to inherit, or use [] for no attachments. |
| `version`         | Yes      | Latest record version; use 0 only when creating a new draft.                                |
| `idempotencyKey`  | Yes      | One content-bound request key; reuse with the identical payload when retrying.              |
| `draftId`         | Yes      | Draft UUID; choose a new UUID when creating, or read the saved draft before updating.       |

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "save_draft",
    "arguments": {
      "draftId": "33333333-3333-4333-8333-333333333333",
      "text": "An unfinished studio update.",
      "connectionIds": ["11111111-1111-4111-8111-111111111111"],
      "mediaIds": ["44444444-4444-4444-8444-444444444444"],
      "textOverrides": {},
      "version": 0,
      "idempotencyKey": "studio-draft-2027-01-18"
    }
  }
}
```
