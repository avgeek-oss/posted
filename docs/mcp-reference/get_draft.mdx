---
title: "get_draft"
description: "Get a draft with Posted MCP."
---

Read a draft's text, selected accounts, overrides and ordered media.

## Workflow

```mermaid
flowchart LR
  step0["Choose a draft"] --> step1
  step1["Read text and account media"] --> step2
  step2["Keep its current version"]
```

## Access and behavior

A Read-only, Write or Administrator OAuth grant can call this tool within the user’s current team role. Tools are listed and callable only when the current grant and role permit them.

Resolved media and mediaOverrides contain media objects. Saving uses mediaIds and mediaOverrides containing IDs.

## Arguments

| Argument  | Required | Type or meaning                                                                       |
| --------- | -------- | ------------------------------------------------------------------------------------- |
| `draftId` | Yes      | Draft UUID; choose a new UUID when creating, or read the saved draft before updating. |

<Accordion title="Complete input schema">

```json
{
  "type": "object",
  "properties": {
    "draftId": {
      "type": "string",
      "format": "uuid",
      "pattern": "^([0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[1-8][0-9a-fA-F]{3}-[89abAB][0-9a-fA-F]{3}-[0-9a-fA-F]{12}|00000000-0000-0000-0000-000000000000|ffffffff-ffff-ffff-ffff-ffffffffffff)$"
    }
  },
  "required": ["draftId"],
  "additionalProperties": false
}
```

</Accordion>

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "get_draft",
    "arguments": {
      "draftId": "33333333-3333-4333-8333-333333333333"
    }
  }
}
```
