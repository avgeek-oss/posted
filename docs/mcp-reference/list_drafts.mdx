title: "list_drafts"
description: "List drafts with Posted MCP."
---

List team drafts. Drafts never enter the delivery queue.

## Workflow

```mermaid
flowchart LR
  step0["Read pending drafts"] --> step1
  step1["Choose a draft ID"] --> step2
  step2["Read its current version"]
```

## Access and behavior

A Read-only, Write or Administrator OAuth grant can call this tool within the user’s current team role. Tools are listed and callable only when the current grant and role permit them.

Drafts are team-owned and never enter the delivery queue. Pagination is numbered and pageSize is at most 100.

## Arguments

| Argument   | Required | Type or meaning                         |
| ---------- | -------- | --------------------------------------- |
| `page`     | No       | One-based page number.                  |
| `pageSize` | No       | Records per numbered page, at most 100. |

<Accordion title="Complete input schema">

```json
{

  "properties": {

      "type": "integer",
      "minimum": 1,
      "maximum": 9007199254740991

      "type": "integer",
      "minimum": 1,
      "maximum": 100
    }

  "additionalProperties": false
}
```

</Accordion>

## Example call

The client initializes the MCP connection before sending this JSON-RPC call. Example records are fictional.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "list_drafts",
    "arguments": {
      "page": 1,
      "pageSize": 20
    }
  }
}
```
